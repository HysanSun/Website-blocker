Manual ▾

三十秒上手

  • 在 Tasks 里输入任务，按 Add。
  • 点任务行首的 ▶（或行尾的 0/3 🍅），弹出计划框。
  • 填「这个任务预计几个单位」，点 All 或直接 Start focus。
  • 跑满计划后系统提问：做完了按 Yes, it's done 归档；没做完按 Not yet 重新估时间。

「单位」是什么

1 单位 = 1 段专注 + 紧跟它的那段休息，时长由上面的 Timer settings 决定 （默认 25 + 5 分钟）。任务行尾的 2/5 读作「已记 2 单位 / 计划 5 单位」。

计划框里的两个数字

  • Planned units (estimate)：这个任务一共值几个单位，随时可改，但不会被 改到低于已经做完的那部分（否则「到达计划」这个提问就再也不会出现了）。
  • Units this session：这次先做几个，上限是「还差几个到计划」； All 一下填满。

计时中能做什么

  • Stop：放弃这一段，不记账，整次 run 一起作废（没做完的单位要重来）。
  • Skip：只有休息能跳。专注期它是灰的 —— 一段专注必须走完， 不想做就用 Stop 认账。
  • Pause / Resume：暂停不解除拦截（专注期照样封站），也不推进计时。
  • run 期间休息一结束会自动进下一段专注，即使关着「自动开始下一段」—— 这是「一直做到做完」的意思。

跟拦截的关系

  • 专注期（暂停也算）把所有 timed 站点按 0 额度封死；block 站点 照旧一直封。
  • 不想要这条就取消 Block timed sites during focus。
  • 专注期被拦下来的标签页不会自己跳回来，刷新一下即可。

数据与统计

  • 计时状态和任务存在扩展本地（关浏览器不丢），设置跟着账号同步。
  • 「今日 N 段 / M 分钟」每天零点清零；循环进度和任务不受影响，未完成任务跨天保留。
  • 做完的任务进 Done 区，永不自动删除，只有 Clear completed 才删。
  • 扩展图标上的角标：专注期橙色显示剩余分钟，休息期绿色。

关机 / 休眠回来之后

到期只看时间戳：回来时若已过截止时间，这段就算完成，但只补记一段（新的一段 从你回来的时刻重新起算），不会把几小时算成几十段。睡过头超过 2 分钟的那次转换不发 系统通知，但照记账。
