Manual ▾

三十秒上手

  • 在 Tasks 里输入任务，按 Add。
  • 点任务行首的 ▶（或行尾的 0/3 🍅），弹出计划框。
  • 填「这个任务预计几个单位」，点 All 或直接 Start focus。
  • 跑满计划后系统提问：做完了按 Yes, it's done 归档；没做完按 Not yet 重新估时间。

「单位」是什么

1 单位 = 1 段专注 + 紧跟它的那段休息，时长由上面的 Timer settings 决定 （默认 25 + 5 分钟）。任务行尾的 2/5 读作「已记 2 单位 / 计划 5 单位」。

计划框里的两个数字

  • Planned units (estimate)：这个任务一共值几个单位，随时可改，但不会被 改到低于已经做完的那部分（否则「到达计划」这个提问就再也不会出现了）。
  • Units this session：这次先做几个，上限是「还差几个到计划」； All 一下填满。

计时中能做什么

  • Stop：放弃这一段，不记账，整次 run 一起作废（没做完的单位要重来）。
  • Skip：只有休息能跳。专注期它是灰的 —— 一段专注必须走完， 不想做就用 Stop 认账。
  • Pause / Resume：暂停不解除拦截（专注期照样封站），也不推进计时。 一次专注只能暂停一次，而且最多 2 分钟 —— 到点计时自己重新走起来， 暂停中会显示还剩多久；之后 Pause 按钮变灰。休息期不受这条限制。 （时长写在 background.js 的 POMODORO_MAX_PAUSE_MS。）
  • run 期间休息一结束会自动进下一段专注，即使关着「自动开始下一段」—— 这是「一直做到做完」的意思。

跟拦截的关系

  • 专注期（暂停也算）把所有 timed 站点按 0 额度封死；block 站点 照旧一直封。
  • 不想要这条就取消 Block timed sites during focus。
  • 例外：想封 baidu.com 又不想连 pan.baidu.com 一起封掉，就在设置里加一条 !pan.baidu.com（! 开头的规则 = 这个站和它下面的子站永远不封）。baidu.com 本身和其余子站照旧被封，别的规则不用加。
  • 专注期被拦下来的标签页不会自己跳回来，刷新一下即可。

时段与临时放行

  • 设置里每条规则可以勾 Only during certain hours。窗口之外这条规则 不存在 —— 不是放宽，是"这一小时没有这条规则"，timed 规则的额度也不计。 跨午夜的窗口（例如 22:00–06:00）算在它开始的那一天。
  • 被拦的整页上有一个 Unlock 30 min：它写一条带过期时间的放行规则，到点自己收回， 列表顶部和设置页都会显示还剩多久。它和 !host 例外是同一套机制 （同一个 allow 规则，只是多了倒计时），不是第二种例外。专注期也按得动它 —— 这一点是有意的：临时的、你自己按的放行，比"删扩展"体面。
  • 放行只按域名生效：pan.baidu.com 的放行不会连带放开 baidu.com。

打印清单

Tasks 标题右边的 Print 只打印清单本身：打开系统打印对话框，页面上其它 卡片（计时器、Done、趋势、设置、这份说明书）都不会出现在纸上，纸面一行一个任务， 前面的方框可以手写打勾。进行中的任务按清单顺序排，已完成的任务带删除线排在最后的 Completed 里。想存成 PDF，在打印对话框的「目标打印机」里选 Save as PDF 即可 —— 扩展本身不生成文件，也不联网。

清单里没有任务时按钮只会提示一句，不会打出空白页；不按这个按钮直接 Ctrl+P， 打印的仍是屏幕上这一页的原本样子。

隐私与权限

  • 这个扩展不联网：代码里没有 fetch / XMLHttpRequest / sendBeacon，没有统计、没有账号、没有第三方服务。提醒音是本地合成的， 不下载音频。仓库根目录的 PRIVACY.md 是完整声明。
  • 它不看网页内容：只拿 location.hostname 和当前标签页的网址， 去和你自己写的规则比对，不读 DOM、不读输入框；读不了密码也读不了聊天记录。
  • 为什么权限看着吓人：<all_urls> 是因为拦截必须在你访问之前 看到网址，而它没法预先知道你会封哪些站；tabs 是为了把时间记在 你正在看的那个站上。两条都只用来比对你自己写的规则。
  • 规则和番茄钟设置走 Chrome 账号同步（storage.sync）； 用量、任务、趋势、临时放行只存在本机，删扩展即随之删除 —— 所以先导出。

快捷键、提醒音与备份

  • Alt+Shift+P 打开这个窗口，Alt+Shift+S 暂停 / 继续当前计时。 快捷键绕不过"一次专注只能暂停一次"这条规则；想改键去 chrome://extensions/shortcuts。
  • Play a chime when a phase ends（默认关）：相位结束时响一声。声音是本地合成的， 不联网、不下载音频文件。关着就完全不出声。
  • 设置页的 Backup 把规则、任务、统计、番茄钟设置一起导出成一个 JSON； 导入是整体替换，不是合并。防的是"删扩展 = 唯一解锁"那一天。

数据与统计

  • Trend 是这台机器上的本地记录：每天记住「跑完几段、共多少分钟、在哪几个站上 把额度用完了」，保留 90 天，更早的自动丢掉。它不参与任何判定 （既不封站也不发通知），也不会同步到你的账号 —— 按小时增长的这类数据写进 同步存储会把设置一起写坏。导出备份时会一起带走。
  • 计时状态和任务存在扩展本地（关浏览器不丢），设置跟着账号同步。
  • 「今日 N 段 / M 分钟」每天零点清零；循环进度和任务不受影响，未完成任务跨天保留。
  • 做完的任务进 Done 区，永不自动删除，只有 Clear completed 才删。
  • 扩展图标上的角标：专注期橙色显示剩余分钟，休息期绿色。

关机 / 休眠回来之后

到期只看时间戳：回来时若已过截止时间，这段就算完成，但只补记一段（新的一段 从你回来的时刻重新起算），不会把几小时算成几十段。睡过头超过 2 分钟的那次转换不发 系统通知，但照记账。
